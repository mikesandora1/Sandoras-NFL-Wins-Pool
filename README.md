# Sandora's NFL Wins Pool

Live site: https://mikesandora1.github.io/Sandoras-NFL-Wins-Pool/

## Hosting
The site is hosted on GitHub Pages. Netlify is no longer required.

## Automatic data updates
NFL data is generated by `.github/workflows/update-pool.yml` using `automation/update-data.mjs`.

The updater runs:
- every morning during the NFL regular season
- every 15 minutes during Sunday game windows
- every 15 minutes during Monday Night Football
- every 15 minutes during Thursday Night Football
- every 15 minutes during late-season Saturday windows

When NFL data changes, the workflow commits the refreshed `generated/current.json` file to `main`.

The public site reads that file directly from GitHub with cache-busting, so routine standings updates do not require a new site deployment.

An open browser tab checks for newly generated data every 5 minutes and redraws the current page when a new version is available.

## Site deployments
`.github/workflows/deploy-pages.yml` deploys the static site to GitHub Pages whenever application code, styles, or configuration on `main` changes.

Routine updates to `generated/current.json` are intentionally excluded from Pages deployments because the site reads that data directly from GitHub.
